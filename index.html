How we use your phone number

Lost in Touch uses SMS for exactly one thing: signing you in. Here's the full picture — the same terms shown in the app before anyone consents to a text.

Message type
One-time 6-digit authentication codes only. No marketing, no promotions, no newsletters.
Frequency
Exactly one message per sign-in attempt — sent only when you request a code, never on a schedule.
Opt-in method
You enter your phone number on the sign-in screen and check a consent box before a code is sent. No box, no text.
Opt-out
Reply STOP to any message to stop receiving texts, or simply stop signing in — we only text you when you ask us to.
Cost
Message and data rates may apply from your carrier.
